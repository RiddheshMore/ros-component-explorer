🔄 Data Processing Pipeline

📊 Data Flow & Transformation

Original Data: components.ttl (SPARQL INSERT format, 1,370 lines)
Conversion: convert_ttl.py → Strip SPARQL wrapper, add Turtle prefixes
Clean Data: components_converted.ttl (Standard Turtle, 1,372 lines)
Enhancement: + expanded_components_ros.ttl (12 premium components)
Indexing: Apache Solr with validation & vector generation
Final: 114 searchable components with AI-powered discovery

🛠️ Key Processing Steps

Format Conversion
SPARQL INSERT → Turtle RDF with proper namespaces
Data Validation
Type checking, "Unknown" value handling, schema compliance
Vector Generation
384-dimension embeddings using all-MiniLM-L6-v2 model
Solr Indexing
Full-text search with semantic vector fields
